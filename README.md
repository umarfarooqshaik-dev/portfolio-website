# Portfolio Website

A Full Stack Portfolio Management System built using Angular, Spring Boot, and MySQL.

## Features

- Admin Login
- Skills Management (Add/Delete Skills)
- Projects Management (Add/Delete Projects)
- Contact Form Integration
- User Responses Dashboard
- Responsive UI Design
- REST API Integration

## Tech Stack

### Frontend
- Angular
- TypeScript
- HTML
- CSS

### Backend
- Java
- Spring Boot
- Spring Data JPA

### Database
- MySQL
