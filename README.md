# portfolio-website
Developed a Full Stack Portfolio Management System using Angular, Spring Boot and MySQL. Features include Admin Dashboard, Skills &amp; Projects Management, Contact Form Integration and REST API based CRUD Operations.

## Features

- Admin Login
- Skills Management (Add/Delete Skills)
- Projects Management (Add/Delete Projects)
- Contact Form Integration
- User Responses Dashboard
- Responsive UI Design
- REST API Integration

## Tech Stack

### Frontend
- Angular
- TypeScript
- HTML
- CSS

### Backend
- Java
- Spring Boot
- Spring Data JPA

### Database
- MySQL
